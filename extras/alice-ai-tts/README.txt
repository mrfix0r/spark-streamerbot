Alice AI TTS — установка в Яндекс Браузер

1. Распакуйте папку alice-ai-tts в постоянное место, например:
   C:\Bots\alice-ai-tts

2. В Яндекс Браузере откройте:
   browser://extensions

3. Включите "Режим разработчика".

4. Нажмите "Загрузить распакованное расширение"
   и выберите папку alice-ai-tts.

5. Откройте:
   https://alice.yandex.ru/

6. Обновите страницу один раз после установки расширения.

7. Задайте Алисе новый вопрос.
   Старые ответы при загрузке страницы специально не озвучиваются.

Настройки голоса находятся в начале content.js:
RATE = 1.05
PITCH = 1.0
VOLUME = 1.0

Скрипт выбирает русский системный голос. В первую очередь ищет
Svetlana / Irina, затем использует первый доступный ru-RU голос.

Если ответ не озвучивается:
- нажмите F12 -> Console;
- найдите строки, начинающиеся с [Alice TTS];
- пришлите их в чат.
