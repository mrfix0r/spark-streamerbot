# Spark · Streamer.bot

Сохранённые действия C# для Twitch-бота Fix0rAI и связанные дополнения стрима.
Каждый файл C# вставляется в отдельное действие Execute C# Code в Streamer.bot;
это не самостоятельное приложение .NET.

## Состав и актуальность

| Путь | Назначение | Дата исходника |
| --- | --- | --- |
| `actions/Spark_Silence_Watchdog.cs` | Реплики при тишине, цикл жизненных и игровых тем | 10.09.2026 |
| `actions/Spark_Chat_Activity_Tracker.cs` | Учёт активности, исключение сообщений своего бота | 04.09.2026 |
| `archive/AI_Reply_2026-08-30.cs` | Сохранённое действие ответа на `!ai` | 30.08.2026 |
| `extras/alice-ai-tts/` | Расширение озвучки ответов Алисы | 27.08.2026 |
| `extras/chat-overlay/` | Локальный чат для OBS | 27.08.2026 |
| `extras/d20-overlay/` | Визуальная часть броска d20 | 24.08.2026 |

Это найденные сохранённые исходники. Полного актуального экспорта Streamer.bot
нет: здесь отсутствуют отдельное действие Auto Chat, код трекера истории для
старого `!ai`, команды `!voice`/приветствий и обработчик броска `!d20`.
Старое действие `!ai` выделено в `archive/`; оно не объявляется последней
рабочей версией. Оверлей чата также сохранён на дату архива и может отличаться
от текущей локальной версии.

## Установка трекера и watchdog

1. Создайте действие `Spark Track Chat` и вставьте код трекера целиком.
   Привяжите его к событию сообщения Twitch-чата.
2. Создайте `Spark Silence watchdog`, вставьте второй файл целиком.
3. Настройте повторяющийся таймер: Interval = 30 секунд, Lines = 0.
   Для watchdog используйте только триггер Timed Actions этого таймера.
4. Назначьте watchdog отдельную очередь `Spark`, чтобы ожидание API не
   задерживало трекер чата.
5. Подключите Twitch Bot account и OBS (connection = 0).
6. В Persisted globals задайте строковый `openai_api_key`. При необходимости
   задайте `ai_bot_username`; имя по умолчанию — `Fix0rAI`.

Ключ OpenAI не хранится в исходниках. Для C# нужны стандартные сборки
Streamer.bot и Newtonsoft.Json. Watchdog использует gpt-5; счёт за генерацию
оплачивается в соответствующем аккаунте API.

Обычная отправка требует активного стрима OBS: 180 секунд тишины, минимум
600 секунд между публикациями, 120 секунд после ошибки. Флаг `spark.testOnce`
в Non-Persisted globals запускает реальную разовую отправку с обходом этих
ожиданий и проверки OBS. Подробности находятся в заголовке исходника.

## Дополнения

У расширения Алисы и оверлея чата есть собственные README. Папка d20 содержит
только визуальную часть; для бросков потребуется действующий обработчик
события из вашей настройки Streamer.bot.

## Проверка и ограничения

Рабочие секреты, журналы, история чата и экспорт настроек Streamer.bot сюда
не включены. C# не компилировался в Streamer.bot при подготовке репозитория;
соответствие вашей установленной версии нужно проверять в его редакторе.
